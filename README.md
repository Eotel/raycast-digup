# DigUp for Raycast

Open [DigUp](https://github.com/ARahim3/DigUp) search from Raycast with **Search with DigUp**. The command uses DigUp's own search window and index.

## Install locally

1. Install DigUp and complete its setup.
2. Run `npm install` and `npm run dev` in this directory to import the extension into Raycast.
3. Run **Search with DigUp** in Raycast. Assign a hotkey or alias in Raycast if you use it often.

If DigUp is outside the standard Applications folders, set **DigUp App Path** in the extension preferences to the full path of `DigUp.app`.

The command opens the app via macOS Launch Services. DigUp shows its search window when reopened.

This extension is an independent project and is not affiliated with the DigUp maintainers.
